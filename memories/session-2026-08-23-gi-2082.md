## Implementation shape

Branch feat/win-pr-monitor-backstop off origin/main at 980381dd.
Empty start commit b89118fe carried the draft PR (#2084);
implementation landed as d5c59b33 before marking ready.

- `hooks/monitor-open-prs.py`: `alive()` probes with OpenProcess /
  GetExitCodeProcess on nt (ctypes, explicit argtypes/restype).
  Refuses pid <= 0 before probing on either platform.
  POSIX keeps signal 0.
- `scripts/install-pr-monitor.py`: schtasks persistence (/SC MINUTE /MO 5),
  `--status` / `--uninstall` verbs (nt-only),
  python3 fallback to sys.executable in resolve_dependencies,
  stop_stale_daemon loads the hook module unconditionally and probes
  through its alive().
- Tests: platform-split stop assertions
  (POSIX unreaped child vs OpenProcess exit-code read),
  stubbed-hook-module determinism for the confirmed-stop path,
  task-command quoting and verb checks, python3 fallback check,
  alive() regression cases. 26/26 local PASS.
- README: Windows paragraph under the install section.

One test lesson worth keeping:
stubbing only the liveness probe left the real `os.kill(SIGTERM)` firing
against a nonexistent pid, so the quiet no-op branch returned None before
the stub was ever reached.
The old test had masked this because its fake kill swallowed both calls.
Stub every syscall on the path, not just the one you are studying.
