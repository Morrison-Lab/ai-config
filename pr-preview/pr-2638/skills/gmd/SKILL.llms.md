# GMD — GIA + MWC + DAYTB

Clear the repo’s **entire** work queue end to end (`gia`) while acting with full decision latitude (`daytb`) and merge authority (`mwc`).

## When this fires

- “gmd”
- “gia mwc daytb”, “/gia /mwc /daytb”
- “burn down the queue and just merge whatever looks good, don’t ask me”

## Procedure

This is a compound macro. Expand it immediately into its three component skills:

1.  **[`gia`](../../skills/gia/SKILL.llms.md)**: Clear the existing PR queue first (Phase 1), then work through the open issues in order (Phase 2).
2.  **[`mwc`](../../skills/mwc/SKILL.llms.md)**: You hold explicit authority to merge the PRs you drive to a clean review verdict.
3.  **[`daytb`](../../skills/daytb/SKILL.llms.md)**: You hold latitude to make subjective design or implementation decisions yourself, rather than blocking the loop to ask the user. Apply the option you would have recommended, note it in your report, and keep moving.

See the `gia` skill for the actual loop mechanics and reporting format.
